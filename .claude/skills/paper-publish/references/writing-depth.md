# 深度解读的写法：对标高赞文章

参考样本：知乎《京东探索研究院推出 DOPD》（2026-10，约 11,800 字，30 张图，26 个三级标题）。
本文是我们和它的差距总结，以及落到 `writing-spec.md` 里的硬规则。

## 一、差距在哪

| 维度 | 参考文章 | 我们（v1，DFlash 第一版） | 结论 |
| --- | --- | --- | --- |
| 篇幅 | ≈11,800 字 | ≈3,000 字 | 不是凑字，是**论证没展开** |
| 三级标题 | 26 个，每个都是判断句 | 10 个左右，多是名词短语 | 标题要写结论，不写分类 |
| 方法章节 | 每个设计：动机 → 公式 → 逐项解释 → 在框架中的位置 | 三块各一段 | **逐个拆设计**，不合并 |
| 论文章节 | 2.3.1–2.3.5 把四种条件分开讲 | 缺 | 有分支/象限/条件的设计要**一个一个讲** |
| 结果 | 每个数字后面跟「差距来自哪」 | 只报数字 | 数字 + 归因，缺一不可 |
| 图 | 30 张，图文交替解释 | 0 张（v1） | 每个论点一张图，8–12 张是下限 |
| 引言 | 1.1 领域演进 / 1.2 前人局限 / 1.3 本文切口 | 一段话 | 引言必须**分三层** |

## 二、硬规则（已写入 writing-spec.md）

### 结构

1. **引言分三小节**：`1.1 领域演进`（前人做到哪一步）、`1.2 失效模式或局限`（为什么不够）、`1.3 本文切口`（从哪个角度破题）。
2. **方法章节逐个拆设计**。一个设计一个三级标题，固定四段式：
   - 设计动机（要解决上文的哪个问题）
   - 公式或判定条件
   - **逐项解释**：每个符号是什么、为什么这样设计（不是复述公式）
   - 在整个框架里的位置（和其它模块怎么配合）
3. **有分支的设计要分支讲**。若论文按条件分了 N 类（象限、阈值、路由），就开 N 个子标题，每类给判定条件 + 损失/做法 + 这样处理的直觉。
4. **实验结果每个数字后跟归因**。格式：「A 比 B 高 X 分（或快 Y 倍），差距来自……」。没有归因的数字不要写。
5. **讨论分四节**：局限（论文自述 + 你的判断分开写）、判断（这个工作真正的贡献）、落地成本、后续方向。**局限必须比结论长或至少同长**。

### 标题

- 三级标题写成**判断句**：「3.2 KV 注入：和 EAGLE-3 的本质区别」✅，「3.2 KV 注入」❌
- 允许带冒号，"前半说明对象、后半给出判断"

### 图表

- **原表 + Markdown 表并存**：主结果表贴论文原表 PNG（`tab-*.png`），同时给一份 Markdown 切片表，方便读者复制和搜索。
- 原表用 `npm run render:table -- --slug=X --pdf=<pdf> --page=<页> --caption="Table N" --out=<name>` 从 PDF 直接裁；
  裁不出来才退回 `--tex=<path>`（LaTeX 转 HTML）或只给 Markdown 表。
- Markdown 表**只给最有信息量的切片**（例如某一个模型温度档），不要照抄 18 列的整表。
- 图之后要有一句「这张图说明了什么」，不要只贴图。

### 篇幅

- 目标 5,000–9,000 中文字。低于 4,000 基本说明论证没展开。
- 不靠堆砌形容词，靠**多拆一层**：把一个段落拆成「问题 → 做法 → 为什么」三句。

## 三、逐项解释的写法（最容易做砸的地方）

参考文章解释 KL 散度的做法：

> 前向 KL 散度：`KL_forward = E_{y~Π_T}[...]`
> 公式中的期望是在教师分布下采样的。这种散度会对学生模型遗漏教师赋予高概率的动作进行惩罚。其结果是鼓励学生模型覆盖教师分布的所有支撑集（模式覆盖，Mode-covering）。

三段：**期望在哪采** → **惩罚什么** → **导致什么行为**。我们的模板应该长这样：

```
$\omega \in \mathbb{R}^{d \times n}$

- $\omega$ 是……，形状……；
- $\pi$ 是……，它的作用是把……变成……；
- 这里的 $\sigma$ 让……，避免……。

**为什么这么设计**：如果换成 X，会……；论文选了 Y，代价是……。
```

## 四、自查清单（写完自己过一遍）

- [ ] 每个三级标题是不是判断句？
- [ ] 方法里每个公式，有没有"逐项解释 + 为什么"？
- [ ] 有分支的设计，是否每个分支单独讲？
- [ ] 每个实验数字后面，是否有一句归因？
- [ ] 主结果表是否贴了原表？
- [ ] 图是否 ≥ 8 张，且每张后面有解释？
- [ ] 局限部分是否和结论同等篇幅？
- [ ] 总字数是否 ≥ 5,000 中文字？
